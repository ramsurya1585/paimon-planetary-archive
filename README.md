# P.A.I.M.O.N.

Planetary Archive, Irminsul Memory, and Observational Network.

An interactive constellation front end for a lore chatbot. Single static page (`index.html`).
Unofficial fan project, not affiliated with or endorsed by HoYoverse.

Lore text is draft and unverified. The chat currently returns sample replies; replace `askLore()` in `index.html` with a real bot call.
